# Video Tutorial Reconstruction

Скилл для превращения GUI-видеоуроков в воспроизводимые инструкции, полный код и
проверенные проекты. Основной источник — происходящее на экране, а не пересказ речи.

## Что делает

- Просматривает всё видео хронологически и подробнее проверяет спорные действия.
  Пиксели важнее субтитров и результатов OCR.
- Сохраняет свидетельства и состояние между батчами для продолжения работы.
- Использует подходящую локальную VLM для объёмного анализа — один запрос за раз.
- Готовит исполнимые промежуточные листинги и полный финальный код.
- Проверяет происхождение скриншотов, совпадение статьи с исходниками, чистый
  импорт проекта и запуск в нужной версии приложения, когда она доступна.
- Разделяет подтверждённые результаты, неоднозначности и непроведённые проверки.

**Это скилл с методикой, а не видеоконвертер одной командой.** Нужны агент с
файловыми, терминальными и визуальными инструментами, vision-модель и средства
работы с видео и целевым приложением. Установка не разворачивает модель или
конвейер обработки. Подробности — в [настройке](references/setup-and-backends.md).

## Установка и использование

Попроси свой harness установить скилл из этого репозитория. Точка входа —
[SKILL.md](SKILL.md), остальные файлы — справочные материалы. За пределами Hermes
вызовы конкретных инструментов могут потребовать адаптации.

Для Hermes:

```bash
hermes skills install warlock-su/video-tutorial-reconstruction/
```

Завершающий `/` нужен для скилла в корне репозитория. Hermes может выдать CAUTION
на пояснения о закодированных картинках или proxy URL; перед применением
`--force` нужно проверить реальные находки.

```text
/video-tutorial-reconstruction Восстанови урок: <ссылка или локальный файл>
```

Перед первым запуском настрой свой backend и проверь один реальный запрос с
картинкой. Частные кадры не отправляются удалённой модели без согласия.

Обновление установки, управляемой Hermes:

```bash
hermes skills update video-tutorial-reconstruction
```

Для работы прямо из checkout Hermes поддерживает
[`skills.external_dirs`](https://hermes-agent.nousresearch.com/docs/user-guide/features/skills):
агент использует файлы репозитория без второй копии. Другие harness используют
собственные механизмы установки и обновления скиллов.

## Проверки

Python 3.10+, без сторонних пакетов:

```bash
python3 -m unittest discover -s tests -v
```

Тесты и CI проверяют целостность скилла, ссылки, переносимость и сохранение правил
качества. Они не запускают видео, VLM, Godot или Unity. Runtime и визуальный
результат проверяются отдельно для каждого восстанавливаемого урока.
