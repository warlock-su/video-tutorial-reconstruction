# Video Tutorial Reconstruction

Скилл для [Hermes Agent](https://hermes-agent.nousresearch.com/docs/), который
помогает превратить GUI-видеоурок в воспроизводимую инструкцию, полный код и
проверенный проект. Основной источник — происходящее на экране, а не пересказ речи.

[English](README.md) · [Инструкции агента](SKILL.md) ·
[Настройка моделей и инструментов](references/setup-and-backends.md) ·
[Источники и авторство](references/attribution.md) · [MIT](LICENSE)

**Это скилл с методикой, а не видеоконвертер одной командой.** Нужны агент,
подходящая vision-модель и инструменты для работы с видео. Установка не загружает
модель и не разворачивает сервер. Чужие видео, проекты и приватные настройки в
репозиторий не входят.

## Что внутри

- Полный хронологический проход по видео и плотная перепроверка спорных действий.
- Сохранение состояния между батчами, работа с промежуточными результатами.
- Локальная VLM для объёмного анализа и аудита, **строго один запрос за раз**
  к локальному backend/GPU. Без скрытой отправки частных кадров в облако.
- Исполнимые промежуточные листинги, без ссылок на ещё не созданные зависимости.
- Проверка скриншотов, совпадения кода статьи с файлами, чистой распаковки и
  запуска проекта в нужной версии приложения, когда она доступна.
- Явное разделение: что подтверждено, что неоднозначно и что не проверяли.

## Обычная установка на другом компьютере

В актуальном Hermes:

```bash
hermes skills install warlock-su/video-tutorial-reconstruction
```

Прочитай результат сканирования стороннего скилла. Некоторые версии сканера
Hermes дают этому репозиторию **CAUTION** из-за команд клонирования в README,
subprocess-тестов Git-обновления или текста про закодированные картинки и секреты.
Разбери реальные находки: такая категория сама по себе не доказывает ни
безопасность, ни утечку. Если проверил текущие файлы и принимаешь именно эти
предупреждения, повтори команду с `--force`. Не обходи неизвестные находки
автоматически; вердикт dangerous остаётся блокирующим. Если список скиллов не
обновился, открой новую сессию Hermes. Использование:

```text
/video-tutorial-reconstruction Восстанови урок: <ссылка или локальный файл>
```

Перед первым видео нужно настроить собственный backend и пройти preflight:
[зависимости и контракт модели](references/setup-and-backends.md).

Обновления опубликованной версии:

```bash
hermes skills check
hermes skills update video-tutorial-reconstruction
```

Это установка-копия, а не Git-папка. Локальные изменения Hermes обычно сохраняет,
пропуская изменённый скилл при обновлении. Сначала разбери и сохрани правки,
не используй принудительную перезапись по умолчанию.

## Режим разработки: скилл прямо из Git-папки

Для общей работы и сохранения новых уроков в исходниках:

```bash
git clone https://github.com/warlock-su/video-tutorial-reconstruction.git   ~/projects/video-tutorial-reconstruction
cd ~/projects/video-tutorial-reconstruction
hermes config get skills.external_dirs --json
```

Если список пустой (`[]`), подключи Git-папку к активному профилю штатной настройкой:

```bash
hermes config set skills.external_dirs '["~/projects/video-tutorial-reconstruction"]'
```

**Если список не пустой — сохрани все его элементы и добавь новый путь** в JSON-массив,
а не заменяй настройку примером выше. Используется активный профиль/`HERMES_HOME`.
Отдельный установщик, symlink, сервис или установка зависимостей не нужны.
Hermes сможет редактировать доступный на запись внешний скилл — это ожидаемо.

**Если скилл уже есть:** сначала сделай резервную копию вне всех `skills/`,
сравни и сохрани накопленные уроки, затем убери старую папку из сканируемого дерева:
локальная копия имеет приоритет над внешней. Не держи установку-копию и внешний
checkout в одном профиле. Открой новую сессию и проверь путь через `skill_view`.
На Windows адаптируй синтаксис оболочки; команда Python может называться `python`.

Почему без symlink: некоторые версии Hermes читают скиллы через ссылку, но
`skill_manage` не находит их для записи новых уроков. Штатный `external_dirs`
поддерживает и чтение, и запись; одного успешного чтения для проверки мало.

### Получать обновления из Git

Перед pull рабочее дерево должно быть чистым. Если есть правки — остановись
и разбери их, не перезаписывай:

```bash
git -C ~/projects/video-tutorial-reconstruction status --short
git -C ~/projects/video-tutorial-reconstruction pull --ff-only
python3 -m unittest discover -s ~/projects/video-tutorial-reconstruction/tests -v
```

Подключённая папка сразу использует обновлённые файлы; переустановка не нужна.
Новая сессия Hermes обновит индекс скиллов. Если `--ff-only` не прошёл, нужно
разобрать расхождение веток, а не делать reset с потерей изменений.

Новые уроки, записанные агентом через `skill_manage`, попадают прямо в Git-папку.
**Автоматического commit/push нет:** правки сначала просматриваются, проверяются,
затем явно публикуются. Настройки моделей, секреты и рабочие материалы видео
хранятся вне этого репозитория. Подробности — в
[правилах сопровождения](references/upstream-and-maintenance.md).

## Проверки

Нужны Git и Python 3.10+; тесты не требуют сторонних Python-пакетов:

```bash
python3 -m unittest discover -s tests -v
```

Тесты и CI проверяют Git-обновление и целостность скилла. Это **не** новый
прогон видео через модель и не запуск Godot/Unity. Для каждого урока отдельно
проверяются нужная версия приложения, runtime и визуальный результат. Пример
Godot smoke-test рассчитан на Godot 4 и требует подстановки путей проекта.
